# Repository Instructions

This repository uses Conventional Commits for commit messages.

Use commit types such as `feat`, `fix`, `docs`, `test`, `refactor`, `build`, and `chore`.

`oictl` is a generic Open WebUI client. Keep code, tests, examples, and documentation independent of any user's identity, organization, unrelated projects, or local environment. Use synthetic names and reserved example domains in fixtures and examples, including for abbreviated identifiers.

Connection settings come from explicit CLI options, supported environment variables, or user-configured profiles; see `README.md`. Do not assume a particular deployment, credential manager, `.env` file, source checkout path, or tool installation location.
